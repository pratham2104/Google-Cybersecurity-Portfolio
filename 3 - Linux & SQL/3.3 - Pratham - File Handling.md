## Find and search files
The analyst team asked me to locate a log file whose lines contain the text string `error`. The  
file is `server_logs.txt` within the directory `logs`. We can examine the actual lines within  
the file by using `cat server_logs.txt` after `cd logs` or directly with `cat /home/analyst/logs/server_logs.txt`. The image below shows the entire  
lines of the text.

![image2](https://github.com/user-attachments/assets/e7cf2cff-b9f5-4d96-8edf-29bcc3035765)

Now, let’s filter this file so it will return a list of the lines that match the text string “error” in that file. The command `grep error server_logs.txt` will make it happen. As the result shows below, there are six lines that match the text string “error”.

<img width="1264" height="208" alt="image" src="https://github.com/user-attachments/assets/15e7fa53-4f1c-40f8-9225-388556b0cbe4" />

The analyst team also would like me to locate files whose names contain `Q1` and `access` within the `users` directory. First, let’s write the command `cd /home/analyst/reports/users` to enter the `users` directory and `ls -la` commands to view all the files within the directory.

<img width="1392" height="468" alt="image" src="https://github.com/user-attachments/assets/90d67fbc-cd53-4569-abe0-27e7634a5bb1" />

This command (`grep`) will allow us to find the files whose names contain `Q1`: `ls | grep Q1` (make sure you’re already in the directory) or `ls /home/analyst/reports/users | grep Q1`. There are three files associated with `Q1`.

<img width="1357" height="114" alt="image" src="https://github.com/user-attachments/assets/996f04eb-8901-4ff6-9dd7-f2d39feb6e96" />

## Create and edit a file
The analyst team would like me to create a new file and edit it. The command `touch tasks.txt` allows us to create a file. On the other hand, the command `nano tasks.txt` allows us to edit a file. Make sure to press CTRL + X to exit from the nano editor. When being asked “Save modified buffer”, press Y to save the new data to the file. Then, please press Enter to confirm that the file name to write is tasks.txt. Use `cat tasks.txt` command to display the contents of the tasks.txt.
