# Automate Cybersecurity Tasks with Python

**Scenario:** Two exercises applying Python to access control and social-engineering awareness.

**What I did:**
- Wrote a Python script that manages an IP allow list for a mock healthcare organization, restricting access to patient records. The function reads the current list, filters out any address flagged for removal, and rewrites the file, replacing a manual access-control process with a repeatable script.
- Worked through a **TCREI** (Task, Context, Reference, Evaluate, Iterate) case study on structuring phishing-awareness training content.

**Files:** `Algorithm_for_File_Updates_in_Python.md`, `TCREI-phishing-training-case-study.md`
