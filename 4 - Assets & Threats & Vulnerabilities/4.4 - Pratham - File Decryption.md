## Scenario
All files in the `/home/analyst` directory have been encrypted.  
The goal is to break the Caesar cipher protecting a hidden file and then decrypt the main encrypted file to reveal the hidden message.

---

## Task 1 – Read the contents of a file

1. **List files in the home directory**:  
   `ls /home/analyst`
   
   **Output**:  
   Q1.encrypted  README.txt  caesar  

3. **View the README file**:  
   `cat README.txt`
   
   **Output**:  
   Hello,  
   All of your data has been encrypted. To recover your data, you will need to solve a cipher.  
   To get started look for a hidden file in the caesar subdirectory.

---

## Task 2 – Find a hidden file and decrypt the Caesar cipher

1. **Navigate to the `caesar` subdirectory**:  
   `cd caesar`

2. **List all files, including hidden ones**:  
   `ls -a`
   
   **Output**:  
   .  ..  .leftShift3

4. **View the contents of the hidden file**:  
   `cat .leftShift3`

5. **Decrypt the Caesar cipher (shift of 3 letters to the left)**:  
   `cat .leftShift3 | tr 'd-za-cD-ZA-C' 'a-zA-Z'`
   
   **Output**:  
   In order to recover your files you will need to enter the following command:  
   openssl aes-256-cbc -pbkdf2 -a -d -in Q1.encrypted -out Q1.recovered -k ettubrute

7. **Return to the home directory**:  
   `cd ~`

---

## Task 3 – Decrypt the encrypted file

1. **Run the provided OpenSSL command**:  
   `openssl aes-256-cbc -pbkdf2 -a -d -in Q1.encrypted -out Q1.recovered -k ettubrute`

2. **Verify the recovered file exists**:  
   `ls`
   
   **Output includes**:  
   Q1.encrypted  Q1.recovered  README.txt  caesar

4. **View the decrypted message**:  
   `cat Q1.recovered`

---

## Conclusion
In this exercise, you practiced:

- Decrypting a Caesar cipher with the `tr` command  
- Using OpenSSL to decrypt an encrypted file and recover data
